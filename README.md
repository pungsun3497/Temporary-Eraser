# Temporary-Eraser

A Krita plugin that allows you to switch to a specific eraser preset(or any other brush preset) only while holding down a shortcut key. 

As soon as you release the key, it swaps back to your previous brush.



# How to Use

1. **Configure the Preset**
   
    Go to Tools > Scripts > Configure Temporary Eraser Preset.
   
    Select the preset you want to use as your temporary eraser.
   
2. **Set the Shortcut**

    Go to Settings > Configure Krita > Keyboard Shortcuts.

    Search for Temporary Eraser (Hold) under the Scripts > Temporary Eraser section.

    Assign your preferred key.

3. **Use**

   

# How to Install

1. Download zip file
  
2. Tools > Scripts > Import Python Plugin from File
